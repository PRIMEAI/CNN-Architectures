Pourquoi le raccourci de ResNet aide le gradient

Moulay Akhloufi

Pendant la rétropropagation, chaque couche multiplie le gradient par sa dérivée locale. Dans un réseau « plain », le gradient qui atteint les premières couches est un produit de L facteurs : il s’éteint (ou explose). Dans un réseau résiduel, xl+1 = xl + F(xl) : chaque facteur vaut 1 + ∂F/∂x, et le « 1 » transmet le gradient directement.

À retenir

Plain : ∂L/∂x0 = ∂L/∂xL · ∏l ∂xl+1/∂xl. Si chaque facteur ≈ 0,5 : 0,520 ≈ 10−6 (gradient évanouissant) ; si chaque facteur ≈ 1,5 : 1,520 ≈ 3 300 (gradient explosif).
Résiduel : xL = xl + Σ F(xi), donc ∂L/∂xl = ∂L/∂xL · (1 + ∂/∂xl Σ F(xi)). Le terme « 1 » est une autoroute : il ne peut pas s’annuler par multiplication (He et al. 2016).
Ce n’est pas seulement un problème de gradient : un réseau plain de 56 couches a même une erreur d’entraînement plus élevée qu’un réseau de 20 couches (problème de dégradation). Avec les raccourcis, il suffit que F apprenne 0 pour obtenir l’identité.
