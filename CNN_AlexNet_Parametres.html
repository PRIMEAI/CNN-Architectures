AlexNet : où sont les paramètres ?

Moulay Akhloufi

AlexNet (2012) compte environ 62 millions de paramètres. Les couches de convolution font presque tout le calcul, mais les couches entièrement connectées (FC) contiennent presque tous les paramètres : ≈ 94 %. Cliquez sur une couche pour voir le détail du calcul.

À retenir

Taille de sortie : O = (W − F + 2P) / S + 1. Paramètres d’une CONV : (F·F·C + 1)·K. Paramètres d’une FC : (entrées + 1)·sorties.
FC6 seule : 6·6·256·4096 ≈ 37,7 M paramètres, plus que toutes les convolutions réunies (≈ 3,7 M). C’est pourquoi GoogLeNet, ResNet… remplacent les grosses couches FC par un pooling global moyen (essayez la variante).
Les chiffres sont ceux de la version « simplifiée » sur un seul GPU (≈ 62 M). L’article original répartit CONV2, CONV4 et CONV5 sur 2 GPU, ce qui donne ≈ 61 M.
